# PRD --- Solo Quest

## Overview
Solo Quest is a gamified productivity application that turns daily tasks into RPG quests, goals into raids, and personal growth into character progression. Inspired by "Solo Leveling", it wraps habit science (variable rewards, loss aversion, streaks, adaptive difficulty) inside classic RPG progression.

## Problem
Streak counters don't spark joy; leveling up does. Existing productivity apps feel like chores. Users abandon habit trackers because there's no emotional hook.

## Goals
- Turn task completion into meaningful XP/gold rewards.
- Provide rank progression (E → S) as visible long-term motivation.
- Maintain daily engagement via dungeons, streaks, and leaderboards.
- Let users own their data (export/delete).

## Target users
Productivity enthusiasts, gamers, students, freelancers, and anyone who wants game-like motivation for real-life work.

## Features (MoSCoW)
**Must have:** Quest CRUD, rank progression, daily dungeons, economy (XP/gold), auth, hunter profile.
**Should have:** Gates/raids, shop, shadow realm, milestones, mastery challenges, social.
**Could have:** Guilds, multiplayer raids, marketplace, mobile (Capacitor).
**Won't have (v1):** Native desktop app, AI coach (planned).

## User stories
- As a hunter, I want to create a quest with a rank so I earn appropriate XP.
- As a hunter, I want daily dungeons so I maintain streaks.
- As a hunter, I want to export my data so I own my information.

## Success metrics
- 70% of users complete at least one quest in first session.
- Daily active retention ≥ 40% at D7.
- Quest completion rate ≥ 60%.

## Out of scope (v1)
Native desktop, AI coaching, full guild economy.
